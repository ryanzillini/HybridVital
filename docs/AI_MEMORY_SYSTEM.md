# AI Memory & Context System

## Philosophy

Mostly automatic memory with user overrides. The “wow factor” comes from the AI just knowing Ryan without being reminded.

## Memory Layers

1. **Permanent Profile** — Conditions, goals, preferences, cooking skill, etc.
2. **Rolling Metrics** — Last 7–30 days of key data (macros, training, energy, constipation)
3. **Learned Patterns** — AI-suggested insights (e.g., “Ryan’s energy drops when fiber is low for 3+ days”)
4. **Live Tool Context** — Fresh data pulled on every chat via tool calling

## Workflow

- User opens AI Coach → Grok automatically gets relevant context
- After conversations/daily summary, AI can propose memory updates
- User can say “Forget that” or edit via Memory Settings screen

## Guardrails

- Conservative health advice
- Always suggest consulting doctor for medical decisions
- User retains full control
